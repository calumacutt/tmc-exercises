# TMC Program

Date: 2026-08-21

Worked example of the format in `data/PROGRAM_FORMAT.md`. Every exercise name
below is a real row in the Movement Library and every class name is from the
declared vocabulary, so this file doubles as an import fixture — if the parser
rejects it, the parser is wrong.

Four classes: the three core ones plus `Handstand`, to show an optional class in
place.
